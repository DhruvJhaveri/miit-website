# MIIT CORPORATION — website

A cinematic, production-ready website for MIIT CORPORATION, an industrial engineering supplies and procurement business in Mumbai, founded as Apco Tools Traders in the early 1970s.

- **Homepage.** A scroll-scrubbed industrial film edited from real, licensed footage, followed by six scroll-driven scenes: product rail, requirement assembly, process, case study, RFQ and closing CTA.
- **Catalogue.** Nine categories and 34 product-family pages, with search and filters.
- **Industries.** Ten industry pages.
- **Procurement solutions.** Includes a Requirement Complexity Planner.
- **Case study.** The published 65-tonne, 130-product export order.
- **Resources.** Ten buyer guides.
- **RFQ and contact.** A multi-step, multi-line-item RFQ with uploads and a real server pipeline, plus a contact form.

## Stack

Next.js 16 (App Router, Cache Components) · React 19 · TypeScript · Tailwind CSS 4 · GSAP + ScrollTrigger · Zod · lucide-react · Vitest · Playwright · ffmpeg/Python media pipeline.

## Quick start

```bash
npm install
cp .env.example .env.local      # optional for local dev; storage-only RFQs work without it
npm run dev                     # http://localhost:3000
```

Submissions are saved to `./.data/` (git-ignored) unless other channels are configured.

| Script | Purpose |
| --- | --- |
| `npm run dev` / `build` / `start` | Develop, build, serve |
| `npm run lint` / `typecheck` | ESLint, TypeScript |
| `npm run test` | Unit tests (Vitest) |
| `npm run test:e2e` | End-to-end tests (Playwright; builds must exist, starts `next start` on :3200) |
| `npm run qa:film` | Screenshots of the scroll film at many positions, plus mobile, reduced-motion and failed-media runs |
| `npm run media:fetch` / `media:build` | Re-download source clips / re-render the film, loops and stills (needs Python 3 + Pillow, and ffmpeg) |
| `npm run odoo:check` | Verify Odoo API credentials before enabling the CRM adapter |

## How the scroll film works

- `ScrollFilm` pins a 100svh stage with CSS `position: sticky`, so the browser's own scrolling is never hijacked.
- One GSAP ScrollTrigger timeline, scrubbed over the section, drives both the canvas frame index and the typography. Forward and reverse stay in sync.
- Frames are WebP images: 240 at 1280×720 for desktop, or 160 at 540×960 for portrait screens. They load in coarse-to-fine passes, and the nearest loaded frame is drawn while the rest arrive.
- The poster is server-rendered.
- Without JavaScript, or with `prefers-reduced-motion`, the section becomes a static hero with all narrative text.

Details are in [`docs/ASSETS.md`](docs/ASSETS.md).

## Editing content

Everything editable lives in `src/content/`. Add a product family by appending to its category's `families` array in `categories.ts`; its page, catalogue card, search entry and sitemap entry are created automatically. Unknown technical fields stay `undefined` and are not rendered. **Do not invent specifications.**
